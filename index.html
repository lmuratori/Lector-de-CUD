      Modo de funcionamiento

      En modo conectado, además de guardar todo en este celular, cada informe se envía a tu backend Apps Script.

      Incluí apps-script-cud-endpoint.gs en el ZIP con el código de ejemplo para tu proyecto.

      Copia de seguridad

      Las carpetas viven solo en este dispositivo. Se recomienda exportar una copia periódicamente (por ejemplo, antes de cambiar de celular o de borrar datos del navegador).

      Datos guardados en este dispositivo

      Carpetas, documentos y clave se guardan solo en este navegador (IndexedDB/localStorage).
